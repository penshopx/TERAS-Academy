# 40. ACCEPTANCE CRITERIA

Phase 1 PASS jika:

### Domain

* [ ] Course formal tersedia.
* [ ] Lesson formal tersedia.
* [ ] Learning Activity formal tersedia.
* [ ] Learning Outcome formal tersedia.
* [ ] Content Resource formal tersedia jika dibutuhkan.
* [ ] Existing Module tetap menjadi anchor.
* [ ] Existing Practice tetap menjadi engine practice.
* [ ] Existing Evidence tetap menjadi engine evidence.

### State

* [ ] Central transition service tersedia.
* [ ] Frontend bukan owner state transition.
* [ ] Valid transitions pass.
* [ ] Invalid transitions rejected.
* [ ] No prerequisite bypass.

### Causality

* [ ] Learning dapat dikaitkan dengan practice.
* [ ] Practice dapat dikaitkan dengan evidence.
* [ ] Evidence dapat dikaitkan dengan review/feedback.
* [ ] Feedback dapat dikaitkan dengan remediation.
* [ ] Remediation dapat dikaitkan dengan re-practice.
* [ ] Re-practice dapat dikaitkan dengan new evidence.
* [ ] New evidence dapat dikaitkan dengan reassessment.
* [ ] Reassessment dapat dikaitkan dengan readiness transfer.

### Safety

* [ ] Existing safety formula unchanged.
* [ ] Critical blocker tetap enforced.

### Pathway

* [ ] Path A/B isolation tetap pass.
* [ ] New LMS records tidak cross-path.

### Authorization

* [ ] Unauthorized transition ditolak.
* [ ] Unauthorized mutation tidak menghasilkan event.

### Data

* [ ] No destructive migration.
* [ ] Existing historical records preserved.
* [ ] Event history append-oriented.

### API

* [ ] OpenAPI valid.
* [ ] Generated clients regenerated.
* [ ] Zod generated.
* [ ] No unexplained breaking API changes.

### Quality

* [ ] Existing tests pass.
* [ ] New tests pass.
* [ ] Typecheck pass.
* [ ] Build pass.

# FINAL STOP CONDITION

Jika menemukan:

* duplicate entity;
* conflicting schema;
* existing state yang tidak kompatibel;
* migration berisiko;
* safety bypass;
* Path A/B contamination;
* authorization gap;
* breaking API contract;
* ambiguity tentang ownership;

**STOP sebelum melakukan perubahan yang berisiko dan laporkan konflik tersebut.**

Jangan menyelesaikan konflik dengan asumsi.

Prinsip akhir:

```text
TERAS EXISTING ENGINE
        +
FORMAL LMS LEARNING LAYER
        +
CENTRAL TRANSITION CONTRACT
        +
```
