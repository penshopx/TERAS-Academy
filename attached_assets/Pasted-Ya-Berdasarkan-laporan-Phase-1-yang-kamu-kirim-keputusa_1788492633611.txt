## Tetapi ada satu hal penting

Saya belum akan menyimpulkan bahwa seluruh LMS sudah "selesai". Justru sekarang kita masuk ke tahap yang lebih penting:

### Task #25 — harus dijaga sebagai hardening

Task #25 sebaiknya **tidak boleh menjadi alasan untuk merombak schema atau transition engine Phase 1**.

Fokusnya:

* migration/upgrade aman;
* existing data tetap utuh;
* migration idempotent;
* deployment baru tidak merusak deployment lama;
* rollback/error handling;
* seed/fixture tidak mencemari production;
* Path A/B tetap terisolasi;
* API tetap kompatibel;
* transition state tidak berubah;
* safety/readiness engine tidak berubah.

### Task #26 — sangat penting untuk UX LMS

Ini sebenarnya jembatan antara **engine Phase 1** dengan **LMS yang benar-benar digunakan learner**.

Karena prinsip yang harus tetap terkunci adalah:
