## Sasaran utama Phase 2

Learner harus selalu bisa menjawab tiga pertanyaan:

**1. Saya sedang belajar apa?**

**2. Saya sudah sampai mana?**

**3. Apa yang harus saya lakukan sekarang?**

Maka pusat UX-nya:

```text
┌─────────────────────────────────────┐
│           MY LEARNING               │
│                                     │
│  Continue Learning                  │
│  Course: ...                        │
│  Module: ...                        │
│  Lesson: ...                        │
│  Activity: ...                      │
│                                     │
│  Progress                            │
│  ███████████░░░ 72%                 │
│                                     │
│  NEXT ACTION                         │
│  Complete: Activity 4               │
│                                     │
│       [ Continue Learning ]          │
└─────────────────────────────────────┘
```

Tetapi progress **tetap hanya progress pembelajaran**.

Tidak boleh ada UX seperti:

> "72% → Anda kompeten."

atau:

> "100% → Anda siap."
